## 软件简介

**CY-AI 音乐助手**是一款面向抖音音乐生态的桌面端 AI 创作工具，整合 **DeepSeek 大模型歌词生成** 与 **妙响 AI 作曲** 两大引擎，实现从「灵感 → 歌词 → 作曲 → 签约 → 发布 → 统计」的全流程自动化。

无论是个人音乐创作者还是批量内容生产者，都能用它高效产出高质量原创音乐作品。

## 核心功能

### AI 歌词创作

| 功能 | 说明 |
|------|------|
| 64 种歌词风格 | 覆盖流行、民谣、摇滚、电子、古风、说唱、R&B、爵士等 8 大类 |
| 深度思考模式 | 接入 DeepSeek 深度思考 + 联网搜索，歌词意境深远不口水 |
| 千种组合维度 | 主题 × 手法 × 意象 × 风格多维组合，每首都独一无二 |
| 风格提示词 | 自动生成含流派、节奏、乐器、人声、情绪的详细提示词 |
| 智能歌名 | AI 自动生成贴合歌词意境的歌名，8 字以内 |
| 实时进度 | 思考阶段实时显示字数，批量生成显示「第 N/总数」 |

### AI 作曲生成

| 功能 | 说明 |
|------|------|
| 双槽并发生成 | 每账号同时 2 个生成槽位，效率翻倍 |
| 同词异曲 | 每首歌词生成 2 个不同作曲版本，提升成品率 |
| 自动轮转 | 额度用完自动切换，无需人工干预 |
| 失败跳过 | 单首失败自动跳过，不卡流程 |

### 全自动签约与发布

| 功能 | 说明 |
|------|------|
| 一键签约 | 全自动签约流程，验证码弹窗输入 |
| 多平台发布 | 支持汽水音乐、抖音双平台 |
| 四种发布方式 | 灵活选择发布策略 |
| 配额预警 | 接近每日上限自动提醒，防止超限 |
| 自动改名 | 歌名不合格自动重新生成，仅改名不重写歌词 |

### 多账号管理

| 功能 | 说明 |
|------|------|
| 扫码登录 | 直接弹出浏览器扫码，登录态自动保存 |
| 绑定组管理 | 主账号 + 子账号分组管理，同组同色标识 |
| 在线检测 | 启动自动检测在线状态，离线提醒重新登录 |
| 独立并行 | 每个账号独立执行流水线，互不等待 |

### 数据中心

| 功能 | 说明 |
|------|------|
| 多平台统计 | 汽水音乐、抖音数据分组展示 |
| 热度追踪 | 歌曲热度、7 日热度实时更新 |
| 使用量统计 | 抖音使用量、7 日使用量 |

## 创作中心

创作中心是软件的核心面板，整合了完整的创作流水线：

```
歌词生成 → AI 作曲 → 自动改名 → 多平台发布 → 数据统计
```

**特点：**
- 每个账号一张可折叠卡片，账号与模板一一对应
- 五个阶段可独立勾选，按需执行
- 任务卡片实时显示各阶段进度
- 生成的作品直接挂在对应任务卡片下方
- 所有配置自动保存，重启不丢失

## 快速开始

### 下载安装

1. 访问官网 [https://cy9527.cn](https://cy9527.cn) 下载最新版安装包
2. 双击运行，按提示完成安装
3. 启动软件，扫码登录抖音账号即可开始

### 首次使用

1. **登录账号**：在账号管理中扫码登录妙响（抖音音乐创作实验室）
2. **配置模板**：在创作中心选择歌曲方向、创作方向、生成数量
3. **启动流水线**：勾选要执行的阶段，点击「开始」
4. **查看进度**：任务卡片实时显示各阶段进度
5. **查看数据**：在数据中心查看发布作品的热度与播放数据
