# CY-AI 音乐助手

> 基于 DeepSeek 的 AI 音乐创作自动化工具

## 功能特性

- AI歌词生成：集成 DeepSeek 深度思考模式，支持 64 种音乐风格
- 批量歌曲生成：并发生成，每首歌词生成多首不同作曲的歌曲
- 自动发布：一键发布到汽水音乐、抖音等平台
- 多账号管理：支持多账号并行操作，互不干扰


## 支持的音乐风格

民谣、电音、古风、摇滚、流行、说唱、R&B、爵士、乡村、古典等 64 种细分风格。
